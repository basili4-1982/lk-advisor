# LK Advisor — ИИ-агент рекомендаций в личном кабинете

По профилю клиента и, опционально, событию сервис отдаёт top-3 уместных предложения
с объяснением и соблюдением бизнес-правил.

Хакатон «ИИкузница 2026», трек «Клиентские сценарии».
Спринт: **26.11.2026 10:00 — 28.11.2026 10:00 МСК**.

**Статус:** каркас сервиса. Сейчас работает `GET /healthz`; движок рекомендаций добавляется в спринте.

## Что делает

- `POST /v1/recommendations` — клиент и событие на входе, top-3 с причиной и evidence на выходе.
- Одна бэкенд-ручка, без интерфейса: показываем движок, а не UI.
- Числа считает код, LLM только формулирует объяснение.
- Бизнес-правила (несовместимость, экспортный контроль, уже куплено, менеджер, склад)
  применяются до LLM; запрещённое не попадает в ответ.
- Если кандидатов нет — fallback на популярное в сегменте.

Не делаем: интерфейс, реальные интеграции, оплату, рассылку, мультитенантность, обучение моделей.

## Быстрый старт

```bash
make run                     # слушает :8080
curl localhost:8080/healthz  # {"status":"ok"}
```

```bash
docker build -t lk-advisor .
docker run --rm -p 8080:8080 lk-advisor
```

Настройки — в `.env.example` (`ADDR`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `DB_PATH`).

## Структура

```text
cmd/lk-advisor/      точка входа, HTTP-сервер, graceful shutdown
internal/config/     настройки из окружения
internal/httpapi/    роутер, middleware, JSON-ответы
internal/recommend/  воронка: интент → кандидаты → правила → скоринг → top-3
internal/catalog/    товары, категории, связи
internal/explain/    шаблон и LLM, проверка чисел по evidence
internal/store/      загрузка каталога, профилей и правил
```

## Стек

Go 1.26, `net/http`, SQLite, Docker.
LLM — DeepSeek V4.1 Flash через RouterAI; без ключа работает шаблонный режим.

## Экономика

Один запрос — один вызов LLM: 2 000 вх. + 300 вых. токенов, **0,048 ₽**.
10 000 запросов — **≈477 ₽/мес** на токены. Подробно: `economics.md`.

## Решения, которые уже зафиксированы

- Бэкенд, без UI. Организатор прямо сказал: интерфейс не важен, покажите движок.
- Mock/синтетические данные. Доступов к продуктиву не будет.
- Внешние LLM API разрешены, ключи свои.
- Ядро — профиль клиента: история покупок, активные лицензии, поведение.
  Событие визита опционально и только уточняет порядок.
- Скоринг детерминированный. LLM только формулирует объяснение.
- Верхний уровень: top-3, главная — первая.
