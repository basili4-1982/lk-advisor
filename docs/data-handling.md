# Обращение с данными

## Что нельзя коммитить

- `Датасет_Рекомендации_ЛК_v4.xlsx` и любые его копии;
- сырые строки `Продажи`, `Клиенты`, `Заказы`;
- реальные `client_id` вида `C00001` и `order_id` вида `O00001`;
- выгрузки БД, `.db`, `.parquet`, архивы фида.

## Что можно

- агрегаты: количества, проценты, распределения категорий;
- псевдо-ID и товарные названия в примерах на питче;
- синтетические логи агентов (`smb-*`, `prod-*`);
- графики и отчёты без сырых строк.

## Где проходит граница

| Контур | Что внутри |
|---|---|
| Открытое демо | синтетика, `smb-*`, `prod-*` |
| Закрытая проверка | реальный датасет, только на хакатоне |
| Публикация | только агрегаты и синтетика |

Данные лежат в локальной PostgreSQL. В репозиторий попадает только код,
который их читает.

## Проверка

```bash
make data-check
```

Скрипт падает, если в трекнутых файлах есть:

- файл `Датасет_Рекомендации...`;
- реальные `C#####` / `O#####` в коде и CSV.
