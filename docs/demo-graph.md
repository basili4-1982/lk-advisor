# Демо-граф связей

Отдельный экран для жюри и клиента: **не админка**, а витрина публичного слоя
реального датасета.

```text
http://localhost:8080/demo/graph
```

## Что видно

| Слой | Значение |
|---|---:|
| Публичные товары | 821 |
| Публичные B2B-связи | 412 |
| Товары в связях | 325 |
| Публичные solo-товары | 496 |
| Скрыто по k<3 | 258 |
| Скрыто B2C k<5 | 33 |

- узлы — товары, цвет — категория;
- рёбра — совместные покупки, толщина — сила связи;
- solo-товары — отдельным внешним кольцом: видно, где связей нет;
- скрытые по приватности товары не показываются поштучно, только в счётчиках.

## Что можно делать

- переключить **B2B / B2C**;
- найти товар по названию;
- кликнуть узел — открывается карточка:
  - покупатели;
  - число связей;
  - B2C-покупатели;
  - список «с этим покупают»;
- кликнуть соседа — перейти по связи;
- скрыть/показать solo;
- отфильтровать категорию;
- зум колесом, панорама мышью.

Deep link для презы:

```text
/demo/graph?select=top
```

Открывает самый связанный товар и его соседей.

## Приватность

Источник — `lk_item_privacy`:

- B2B: у товара ≥3 покупателя, у пары ≥3 B2B-покупок;
- B2C: у товара ≥5 физлиц, у пары ≥5 B2C-покупок;
- B2C-счётчики меньше 5 отдаются как скрытые.

Товары и пары ниже порога не попадают в nodes/edges, а не просто прячутся
CSS-ом.

## API

```text
GET /demo/graph
GET /v1/demo/graph?audience=b2b|b2c&solo_limit=1000
```

Ответ:

```json
{
  "audience": "b2b",
  "nodes": [{"id": "...", "title": "...", "category": "security", "degree": 27, "solo": false}],
  "edges": [{"source": "...", "target": "...", "count": 50, "b2b_count": 50}],
  "coverage": {"public_items": 821, "public_pairs": 412},
  "connected": 325,
  "public_solo": 496,
  "shown_solo": 496
}
```

## Реализация

- без внешних JS-библиотек: canvas + собственный force layout;
- layout считается один раз при загрузке, затем только pan/zoom/redraw;
- solo-узлы фиксированы на внешнем кольце, чтобы не раздувать force-граф;
- на экране нет сырых строк датасета, только агрегированные названия и счётчики.
