# Демо-граф связей

Отдельный экран для жюри и клиента: **не админка**, а витрина публичного слоя
реального датасета.

```text
http://localhost:8080/demo/graph
```

Запуск закрытого демо:

```bash
DEMO_ALLOW_REAL_DATA=1 go run ./cmd/lk-advisor serve
```

Без флага API графа выключен, чтобы реальные данные нельзя было случайно
опубликовать.

## Что видно

| Слой | Значение |
|---|---:|
| Публичные товары | 817 |
| Публичные B2B-связи | 412 |
| Товары в связях | 325 |
| Публичные solo-товары | 492 |
| Скрыто по k<3 | 0 |
| Скрыто B2C k<5 | 0 |

- узлы — товары, цвет — категория;
- рёбра — совместные покупки, толщина — сила связи;
- 3D-сцена: вращение мышью, колесо — масштаб;
- solo-товары скрыты по умолчанию, чтобы граф читался; включаются тумблером;
- скрытые по приватности товары не показываются поштучно, только в счётчиках.

## Что можно делать

- переключить **B2B / B2C**;
- отфильтровать **семейство товаров**, **отрасль** и **сегмент** клиента;
- отфильтровать категорию товара;
- найти товар по названию;
- кликнуть узел — открывается карточка:
  - покупатели;
  - число связей;
  - B2C-покупатели;
  - список «с этим покупают»;
- кликнуть соседа — перейти по связи;
- клик по узлу включает **focus-режим**: показывается вся связная компонента товара, а не только прямые соседи;
- прямые соседи цветные, дальние узлы компоненты приглушены;
- «Показать всех», `Esc` или клик по фону выключают focus;
- листать страницы по 250 / 500 / 1000 точек;
- перейти по внешней связи на другую страницу;
- скрыть/показать solo;
- отфильтровать категорию;
- выбрать месяц на таймлайне;
- зум колесом, вращение мышью.

Deep link для презы:

```text
/demo/graph?select=top
/demo/graph?period=2026-09&select=top
/demo/graph?industry=ИТ%20(разработчики)&segment=small
```

Первый открывает самый связанный товар, второй — ещё и сентябрь 2026,
третий — сегмент IT / small.

## Пагинация и внешние связи

Граф отдаётся страницами. По умолчанию 1000 узлов, можно 250/500.

- на странице рисуются только её узлы и внутренние рёбра;
- связь с узлом на другой странице не теряется: она попадает в
  `external_edges` с номером страницы;
- узел с внешними связями подсвечивается янтарным;
- в карточке узла есть блок «За пределами страницы»;
- клик по внешнему соседу загружает его страницу и сразу открывает карточку.

## Временной слой

Таймлайн меняет не структуру графа, а спрос на узлах:

- размер узла — покупатели за выбранный месяц;
- зелёное кольцо — рост к прошлому месяцу, красное — падение;
- если за месяц меньше k покупателей, цифра скрыта, узел приглушён;
- в карточке видно: покупателей за месяц, рост, «было» в прошлом месяце.

Порог периода:

- B2B — 3 покупателя;
- B2C — 5 физлиц.

## Продление

Для публичных товаров с ≥5 повторными покупками считается:

- доля повторов в окне 300–430 дней;
- медианный интервал.

Это видно в карточке товара. Для остальных — «мало данных».

## Сегменты

Фильтры:

- `audience`: `b2b` / `b2c`;
- `industry`: отрасль клиента;
- `segment`: `small`, `medium`, `corporate`, `enterprise`;
- категория товара — на клиенте, по легенде.

При выборе отрасли/сегмента публичность пересчитывается **внутри сегмента**:
товар виден, если в этом сегменте у него ≥3 покупателя (B2B) или ≥5 физлиц
(B2C). Поэтому маленький сегмент честно становится разреженным.

## Приватность

Источник — `lk_item_privacy` для всего каталога и сегментные пороги для
фильтрованного графа:

- B2B: у товара ≥3 покупателя, у пары ≥3 B2B-покупок;
- B2C: у товара ≥5 физлиц, у пары ≥5 B2C-покупок;
- B2C-счётчики меньше 5 отдаются как скрытые.

Товары и пары ниже порога не попадают в nodes/edges, а не просто прячутся
CSS-ом.

## Только просмотр

Граф — демо-витрина. Создание и подтверждение связей остаётся в админке и
конструкторе, не в графе.

## Реализация

- 3D: `3d-force-graph` 1.80.2 на Three.js + d3-force-3d;
- библиотека лежит локально: `internal/httpapi/static/3d-force-graph.min.js`,
  без CDN;
- 817 узлов / 412 связей — комфортный demo-размер;
- solo по умолчанию скрыты, чтобы камера не отъезжала на пустое облако;
- на экране нет сырых строк датасета, только агрегированные названия и счётчики.

## Масштаб

Для всего каталога (136k офферов) 3D-граф не строим. Нужны:
- ego-граф на 1–2 hops;
- кластеры по категории/вендору;
- серверный layout или 2D WebGL для десятков тысяч узлов.
