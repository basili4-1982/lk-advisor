# Демо-импорт новых позиций

Файл: `positions_store_demo.csv`

Источник названий: [store.softline.ru/programmirovanie](https://store.softline.ru/programmirovanie/)
(первая страница каталога). В файл попали только позиции, которых не было в `lk_items`.

## Как показать

1. Открыть **Каталог**.
2. Нажать **«Импорт»**.
3. Выбрать `docs/demo/positions_store_demo.csv`.
4. **«Загрузить»** — ожидаемо `Добавлено: 21`.
5. Нажать **«Сгенерировать»** — появятся 9 структурных связей.
6. Открыть пресет **«Структурные»**, найти, например, `FastReport`:
   `FastReport .NET Ultimate → FastReport .NET Ultimate. Продления`.

Импорт не удаляет существующие связи и алиасы: это upsert по `item_id`.

## Ограничения

- `item_id`/`sku` синтетические (`STORE-...`), потому что в карточках store нет артикула.
- `product_group` сгруппирован по вендорским семействам для демонстрации структурных связей.
- Цены и наличие не переносим: в демо важны позиции, а не коммерческие условия.
