| Источник | Тип | Статус | Что даёт | Ограничение |

## Что даёт каждый

**Реестр Минцифры** — идентичность: вендор, класс, реестровый номер, ссылка,
альтернативные названия. Уже дал 32 083 продукта и 157 классов.

**Страницы вендоров** — платформы, редакции, состав продукта. На них держится
подтверждение `upgrade`/`bundle`/`adjacent_task`.

**ФСТЭК** — сертификаты и классы защиты. Нужен файл выгрузки.

**Wikidata** — быстрый способ получить вендора, жанр и официальный сайт, но
российское ПО покрыто неравномерно.

**Госзакупки** — реальные совместные закупки в тендерах. Это внешний аналог
co-purchase, которого нет в истории продаж.

**Softline** — атрибуты и связанные товары из того же каталога, откуда взят
датасет.

**Матрицы совместимости ОС** — ключ к проверке платформы: Astra Linux, Red OS,
Alt Linux.

**NVD/CVE** — для security-линеек: уязвимость может сделать альтернативу
релевантной.

## Приоритет следующих подключений

1. **Матрицы совместимости Astra Linux / Red OS / Alt** — закрывают проверку
   платформы, которую мы сейчас помечаем как `unverified`.
2. **Softline** — атрибуты и связанные товары для оставшихся 450 SKU.
3. **Госзакупки** — внешний сигнал совместных покупок.
4. **ФСТЭК** — сертификаты для security-класса, когда будет файл.
5. **Wikidata** — как дешёвый справочник вендоров и сайтов.
