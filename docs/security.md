# LK Advisor — безопасность стенда

## Доступ

Демо открыто по требованию организаторов: авторизации нет, админка и API
доступны без логина. Это осознанное ограничение демо-стенда, а не продакшена.

## Что закрыто

- **Промпт разметки.** Экран «Промпт для разметки связей» и эндпоинт
  `/v1/admin/relation-types/prompt` удалены. Промпт собирается на сервере и
  не отдаётся наружу.
- **Редактирование шаблонов.** Создание, изменение и удаление типов связей
  удалены из админки и API: шаблоны, из которых собирается промпт, больше
  нельзя менять на живую. Вкладка «Типы связей» оставлена только для просмотра (read-only).
- **Системный промпт.** Вынесен в переменную окружения
  `RELATION_SYSTEM_PROMPT`; в репозитории остаётся только минимальная
  техническая схема ответа.
- **Индексация.** `X-Robots-Tag: noindex, nofollow` и `robots.txt` с
  `Disallow: /` — стенд не попадает в поиск.

## Контейнеры

- `lk-app`: non-root, read-only rootfs, `tmpfs /tmp`, `no-new-privileges`,
  порт 8080 не опубликован на хост;
- `lk-db`: только внутри Docker-сети, наружу порт не отдаётся;
- публичный вход — Caddy: TLS Let's Encrypt, HSTS, `nosniff`,
  `X-Frame-Options`, `Referrer-Policy`.

## Границы агента

LLM-агент не имеет shell, файловой системы и произвольного HTTP. Его
инструменты — чтение профиля, лицензий, заказов, каталога, связей и правил.
Prompt injection может исказить текст ответа, но не даёт выполнить команду
на сервере или прочитать переменные окружения.

## Остаточные риски демо

- без авторизации любой посетитель может смотреть админку и менять связи,
  гипотезы и правила;
- публичный `/v1/ask` расходует LLM-квоту;
- для продакшена нужны SSO, роли, rate limit, аудит и секрет-менеджер.
