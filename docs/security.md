# LK Advisor — безопасность стенда

## Доступ

Демо открыто: авторизации нет. Админка, админ-API и `/v1/ask` работают,
изменения включены.

## Единственное ограничение — промпт

- Экран «Промпт для разметки связей» и эндпоинт
  `/v1/admin/relation-types/prompt` удалены: промпт не отдаётся наружу.
- Системный промпт вынесен в переменную окружения `RELATION_SYSTEM_PROMPT`;
  в репозитории остаётся только техническая схема ответа.
- Шаблоны типов связей редактируются в админке, но сам промпт и его сборка
  снаружи недоступны.

## Контейнеры

- `lk-app`: non-root, read-only rootfs, `tmpfs /tmp`, `no-new-privileges`,
  порт 8080 не опубликован на хост;
- `lk-db`: только внутри Docker-сети, наружу порт не отдаётся;
- публичный вход — Caddy: TLS Let's Encrypt, HSTS, `nosniff`,
  `X-Frame-Options`, `Referrer-Policy`, `noindex`.

## Границы агента

LLM-агент не имеет shell, файловой системы и произвольного HTTP. Его
инструменты — чтение профиля, лицензий, заказов, каталога, связей и правил.
Prompt injection может исказить текст ответа, но не даёт выполнить команду
на сервере или прочитать переменные окружения.

## Остаточные риски демо

Демо открыто по требованию организаторов, поэтому снаружи доступны изменения
связей, гипотез, правил, запуск генерации, импорт, сброс каталога и `/v1/ask`.
Это принятое ограничение стенда; для продакшена нужны SSO, роли, rate limit,
аудит и секрет-менеджер.
