# План закрытия недочётов перед демо

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Закрыть шесть разрывов, которые жюри увидит на демо: холодный старт, старый демо-кабинет, дата фида, подтверждённые связи в графе, сигналы агента и сценарий показа.

**Architecture:** Каждая задача — отдельный срез: клиентская витрина `/lk`, корневая страница, реестр фида, граф, карточка связи. Сервер остаётся на Go + PostgreSQL; UI — встроенные HTML/JS без сборки. Данные датасета не коммитятся.

**Tech Stack:** Go 1.x, PostgreSQL, `database/sql`, `lib/pq`, встроенные HTML-страницы, `go test`.

**Spec:** `docs/hypothesis-platform.md`, ответы жюри (9 пунктов), `docs/data-handling.md`.

## Global Constraints

- Сырые строки датасета и реальные `client_id` не коммитить.
- Демо на реальном датасете запускается только с `DEMO_ALLOW_REAL_DATA=1`.
- В клиентском виде (`/lk`) нет `product_id`, `trace_id`, вариантов и служебных причин.
- Типы и названия в UI — по-русски, идентификаторы кода — английские.
- Показы считаются только по реальным открытиям `/lk`; автоматических накруток нет.

## Review Focus

- Клиент без истории покупок должен получать непустой блок, а не пустой экран.
- Старый демо-кабинет не должен показывать продление как рекомендацию.
- Дата фида не должна выдаваться за дату истории продаж.
- В графе подтверждённые и неподтверждённые связи должны различаться визуально и в легенде.
- Карточка связи без evidence должна честно писать «источник не указан».

## Ledger

- Ruling: cold-start clients are synthetic `COLD-*` records — the dataset has no clients without orders (verified: 0). Cost if wrong: jury may ask why the profile is not real; the system panel labels it as a test profile.
- Ruling: used existing `relations.evidence` JSONB instead of a new `relation_sources` table — the UI and API already render evidence kinds. Cost if wrong: less structured storage, but enough for the demo.
- Ruling: dataset items get `feed_updated_at = 2026-11-26` (snapshot date) because the daily feed does not provide per-row timestamps. The UI says "обновлён", not "ежедневный фид".
- Ruling: legacy `/` replaced by a landing page; `/demo` still serves the old synthetic cabinet for compatibility.
