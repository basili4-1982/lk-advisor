# LK Advisor — рекомендации в личном кабинете

## 1. Подход и архитектура

Бэкенд-сервис с одной ручкой. На вход — клиент и, опционально, событие в кабинете. На выход — top-3 рекомендации: товар, тип, score, причина и evidence.

```text
кабинет → клиент (+ событие) → API → профиль → кандидаты → правила → скоринг → объяснение → JSON
```

LLM не выбирает товар и не считает. Она формулирует причину по готовым данным. Правила применяются до скоринга.

## 2. Стек и модели

- Go 1.26, `net/http`, JSON.
- PostgreSQL 16: каталог, история, правила, профиль в материализованном представлении по шардам.
- LLM — DeepSeek V4.1 Flash: формулирует ответ по отчёту; числа проверяются по evidence, без ключа — шаблон.
- Docker для запуска.
- Модель называется в описании при сдаче; ключи свои.

## 3. Как работает

1. Сигналы: история покупок, активные лицензии, поведение клиента; событие визита — если пришло.
2. Связи: строим сами — LLM извлекает из карточек, валидатор подтверждает.
3. Кандидаты: продление, апгрейд, аксессуар, расходник, аналог.
4. Правила: несовместимость, экспортный контроль, уже куплено, менеджер, склад.
5. Скоринг: релевантность, срочность (включая срок акции), близость покупок, маржа, уверенность; активная акция решает равенство score.
6. Разнообразие: не больше одной рекомендации одного типа.
7. Объяснение: шаблон или LLM, с проверкой чисел по evidence.
8. Fallback: популярное в сегменте, если кандидатов нет.
9. Агент: `/v1/ask` вызывает инструменты, помнит сессию и отвечает по отчёту из БД.

## 4. Реализовано / не реализовано

**Реализовано:** синтетические данные, загрузчик, правила, кандидаты, скоринг, акции, API, объяснение, агент `/v1/ask`, guard, тесты, eval на 50 кейсах.

**Не реализовано:** интерфейс, реальные интеграции с кабинетом, авторизация, платежи, мультитенантность, обучение моделей.

## 5. Стоимость эксплуатации и внедрения

Допущения: 10 000 запросов в месяц, 2 000 входных и 300 выходных токенов на объяснение.

| Статья | Оценка |
|---|---:|
| Запрос без LLM | < 0,01 ₽ |
| Запрос с объяснением | 0,048 ₽ |
| LLM на 10 000 запросов | ≈477 ₽/мес |
| Инфраструктура | 1 500–3 000 ₽/мес |
| Внедрение | 80–120 ч, 240 000–360 000 ₽ |
| Пилот | 4–6 недель, один сегмент |

Экономия и рост выручки считаются в пилоте: CTR, принятие, повторные покупки, средний чек.

## 6. Наработки и компоненты

**До старта:** только проектирование — бриф, контракт API, модель данных, алгоритм, сценарии, приёмка. Код продукта не писался.

**Сторонние компоненты:** Go, SQLite/PostgreSQL, LLM API, Docker. Все — по открытым лицензиям; перечень уточняется при сдаче.

## 7. Соответствие задаче

- клиент получает персональные предложения: дополнительные товары, расширенную версию продукта, продление лицензии;
- учитываются история покупок, активные лицензии и поведение клиента;
- связи товаров строим сами: LLM извлекает из карточек, валидатор подтверждает;
- запрещённое не показывается;
- есть объяснение, почему предложение подходит, и метрики;
- данные синтетические, доступы к продуктиву не нужны.
